# Затейники — сайт праздничного агентства

Лендинг для команды «Затейники» (Великий Новгород), который объединяет четыре направления:
[Затейники](https://vk.ru/zateynikivn), [Loft Z](https://vk.ru/loftzvn), [Квест-зона](https://vk.ru/kvestzonevn), [Сюрприз на праздник](https://vk.ru/surprisenaprazdnik).

## Что внутри

- **Моушен-графика**: [GSAP](https://github.com/greensock/GSAP) (ScrollTrigger, SplitText, Flip) + плавный скролл [Lenis](https://github.com/darkroomengineering/lenis)
  - прелоадер со счётчиком и шторками
  - побуквенное появление заголовков
  - фигуры в hero с параллаксом от мыши и «дыханием»
  - бегущая строка, которая ускоряется от скорости скролла
  - направления — горизонтальный скролл с закреплением (на мобильных — вертикальный список)
  - фильтр программ с FLIP-анимацией, 3D-наклон карточек
  - рисующаяся линия «как это работает», счётчики цифр, перетаскиваемая лента отзывов
  - магнитные кнопки, кастомный курсор, конфетти после заявки
  - уважает `prefers-reduced-motion` (все анимации отключаются)
- **Конструктор праздника** с живым расчётом цены
- **Заявка** → Telegram через serverless-функцию `api/lead.js`. Если сервер не настроен — текст заявки копируется и предлагается отправить в ВК.

## Запуск

```powershell
npm install
npm run dev       # http://localhost:5173
npm run build     # готовый сайт в папке dist
```

## Как поменять контент

Весь текст, цены, программы, отзывы и контакты — в `src/data.js`.
Всё, что помечено `ЗАМЕНИТЬ`, — демо-данные: **перед запуском подставь реальные** телефон, адрес, цены, цифры и отзывы.

## Деплой и заявки в Telegram (Vercel)

1. Импортировать репозиторий в Vercel (фреймворк Vite определится сам).
2. Создать бота у @BotFather, добавить его в чат менеджеров.
3. В настройках проекта добавить переменные окружения:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — id чата (узнать можно через @getmyid_bot или `getUpdates`)
4. Задеплоить. Заявки с сайта будут приходить в Telegram.

На обычном хостинге без серверных функций сайт тоже работает — просто заявки пойдут через фолбэк в ВК.
